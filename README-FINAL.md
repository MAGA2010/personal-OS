# PathOS

PathOS 是一个面向美国本科留学申请场景的地图探索、院校数据与 AI 辅助决策 Demo。

## 当前状态

- 当前版本已冻结归档，不再继续开发或优化。
- 数据边界：62 所学校、62 条 Summary、62 条 Detail、904 条 verified records。
- 地图 Demo 另含 4 项州级指标、204 条记录和 51 个州级辖区。
- 当前数据为 Preview：`sourceLimited=true`、`incomplete=true`、`notFinal=true`。
- Production Data Export 禁止。
- 公网 Vercel 地址仅为 Demo / Preview，不是生产级发布。
